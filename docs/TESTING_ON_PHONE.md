# 在手机上测试 Pinnit 克隆版（APK）

本指南用于把打包好的 APK 装到安卓手机上测试，并开启「通知历史/监听」功能。

## 1. 安装 APK

1. 把 `pinnit-release.apk` 通过微信/数据线/网盘传到手机。
2. 手机打开文件，**允许「未知来源」安装**（首次安装会弹窗，按提示到设置里开「允许来自此来源的应用」）。
3. 点安装，装好后打开 **Pinnit**。

> 包名：`com.pinnit.flutter`
> 当前为 **debug/release 未签名增强版**，首次安装正常；若提示「已安装同名应用」，先卸载旧版再装。

## 2. 开启「通知监听」权限（关键）

不开启这个权限，App 收不到其它 App 的通知，历史列表就是空的。

1. 打开 Pinnit → 底部进入 **历史（History）** 页。
2. 页面顶部会出现一条提示横幅，点 **「开启通知访问」**。
3. 系统跳到 `设置 → 应用 → 特殊应用权限 → 通知使用权`（不同品牌路径略有差异，如小米在「通知管理 → 通知过滤/通知使用权限」）。
4. 在列表里找到 **Pinnit**，打开开关。
5. 返回 App，历史页横幅消失即代表已授权。

开启后，其它 App 弹出的通知（微信、短信、邮件、各类推送）会被自动记录到历史列表，
可搜索、可写备注、可删除单条或清空。

## 3. 主页功能（Pin 笔记）

- 首页是「置顶笔记（Pin）」列表：点右下角 `+` 新建一条，可设标题、内容、是否常驻通知、是否定时。
- 设为常驻后会在通知栏保留一条持续通知；设定时间后会定时弹出。
- 顶部放大镜可搜索笔记。

## 4. 反馈 Bug

测试中发现任何问题，请直接 **截图** 发给我，并尽量说明：

- 出现在哪个页面（主页 / 历史 / 编辑器）
- 操作步骤（点了什么、之前做了什么）
- 手机型号 + 安卓版本（设置 → 关于手机）
- 是否开启了通知访问权限
- 报错文字（如有红字/弹窗，截图即可）

我会根据截图定位并修复，重新打包给你。

## 5. 已知边界（当前版本）

- 通知监听依赖系统授权，部分国产 ROM（小米/华为/OPPO）可能限制后台，需在电池优化里把 Pinnit 设为「不限制」。
- 当前仅打包 `arm` / `arm64` 架构（覆盖 99% 手机）；ChromeOS/模拟器（x64）未包含。
- 定时通知使用精确闹钟，需授予「安排精确闹钟」权限（Android 12+）。
